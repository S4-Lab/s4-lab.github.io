Our Research

Wireless Sensing Systems

We develop energy-efficient sensor solutions for challenging environments — oceans, farms, forests — that lack power and communication infrastructure. Addressing the need to monitor large areas sustainably requires rethinking how sensors communicate, harvest energy, and are deployed at scale.

FarmBeats

End-to-end AI and IoT platform for data-driven agriculture (now on Microsoft Azure Marketplace)

OSPREE

Drone-deployable profiler for low-cost, scalable ocean observation (ACM MobiSys 2026)

Wireless Johnson Noise Thermometry

Passive temperature sensing using the thermal noise of a resistor (IEEE Journal of Microwaves 2025)

Wireless Communication

We explore fundamentally new approaches to wireless communication that require no powered RF transmitter — using thermal noise, backscatter, and even cosmic noise sources as the basis for communication. These techniques enable sensors to transmit data with near-zero power budgets.

Johnson Noise Communication

Transmitting data by modulating the thermal noise of a resistor — no RF generation required (PNAS 2022)

SARLink

Satellite backscatter using Synthetic Aperture Radar for remote sensor connectivity (ACM SenSys 2025)

Cosmic Backscatter

Using extraterrestrial noise sources for wireless communication (ACM HotNets 2023)

Glaze

Overlaying IoT transmissions on occupied spectrum (ACM IMWUT 2020)

WHISPER

Long-range IoT in the TV White Space spectrum (USENIX NSDI 2022, ACM GetMobile 2022)

Energy-efficient Computing for Embedded Systems

We create lightweight machine learning approaches for resource-constrained microcontrollers, enabling on-device intelligence for sensing and robotics over extended battery life. Our focus is on hyperdimensional computing and other brain-inspired paradigms that run efficiently on tiny processors.

HyperCam

Onboard computer vision for IoT cameras using hyperdimensional computing (ACM MobiCom 2025)

NavHD

Low-power navigation for micro-robots using brain-inspired HDC (IEEE IROS 2025)
