## Abstract

Data from on-farm sensors can help farmers make better decisions. Yet building an always-on, connected IoT system for farms is hard because farms lack network connectivity and power infrastructure. We present FarmBeats, an end-to-end IoT platform for data-driven agriculture. FarmBeats uses TV white spaces for farm connectivity, uses drones to map fields, and uses machine learning to fill in gaps in sensor data. FarmBeats has been deployed on multiple farms across the US and shown to improve farm yields and reduce resource usage. FarmBeats is currently available on Microsoft Azure Marketplace.
